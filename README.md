# Repositorio de Estructuras de Datos I

El proyecto principal es **Sonoteca**, un reproductor de música local de
nivel intermedio desarrollado en Python con MVC y Flet. Permite importar
canciones, escuchar y crear playlists. Las listas, pilas y colas propias
sostienen el funcionamiento interno de la aplicación.

- [Sonoteca: alcance, ejecución y estado](proyectos/playlist/README.md).

`proyectos/playlist/` contiene el reproductor actual. `codigo/` conserva
los ejercicios de la asignatura. El prototipo anterior y los temporales de
compilación se retiraron del directorio de trabajo.

Los materiales de exposición, datos personales y distribuciones generadas
se conservan fuera del contenido versionado.
